# Nébula — landing page interactive

Landing page responsive en français pour une application fictive de gestion de projets. Le projet met en pratique HTML5 sémantique, CSS responsive et JavaScript ES6 avec jQuery.

## Fonctionnalités

- Aperçu de la page d’accueil et navigation par ancres.
- Sélection de trois offres avec récapitulatif tarifaire actualisé.
- Comparaison des offres affichable avec jQuery.
- Formulaire d’essai avec validation d’adresse e-mail côté client et retours accessibles.
- Compteur de caractères, état visuel au focus et message d’aide.

Les messages dynamiques sont insérés avec `textContent` ou les méthodes texte de jQuery ; aucune donnée utilisateur n’est interprétée comme du HTML. Le formulaire est une démonstration côté client et n’envoie pas les données à un serveur.

## Lancer le projet

Ouvrez `index.html` directement dans un navigateur, ou ouvrez le dossier dans VS Code et lancez la page avec l’extension **Live Server**. jQuery est chargé depuis son CDN : une connexion Internet est nécessaire pour les interactions jQuery.
